Guardian

System-wide content & privacy blocker for rooted Android.

Blocks ads, trackers, malware, gambling and adult domains by replacing the system hosts file. Works on Magisk, KernelSU / KernelSU-Next, APatch, FolkPatch and SukiSU.

If one site still loads, turn off your browser’s own secure DNS (Chrome → Settings → Privacy and security → Use secure DNS → Off).
